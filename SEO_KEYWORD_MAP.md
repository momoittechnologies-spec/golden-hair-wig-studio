## 3. Structural Rules & Safeguards

1. **One H1 Rule:** Exactly one semantic `<h1>` tag per page, followed by logical `<h2>` and `<h3>` heading hierarchies.
2. **Anti-Duplication:** Each location page contains bespoke paragraphs detailing surrounding landmarks, transit routes, and regional client considerations rather than automated city-swapped boilerplate.
3. **Canonical Discipline:** All canonical links specify `https://golden-hair-wig-studio.pages.dev` with self-referencing trailing paths.
4. **Structured Data:** Every page includes appropriate Schema.org JSON-LD (`HairSalon` with coordinates, addresses, and opening hours; `BreadcrumbList` for inner pages).
